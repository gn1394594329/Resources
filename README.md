# FFXIV Lemegeton Blueprint

提供給 Dalamud 插件 [Lemegeton](https://github.com/paissaheavyindustries/Lemegeton) 讀取的 `blueprint.xml`，包含各伺服器的網路封包 opcode 對照表。

## 使用方式

在 Lemegeton 設定中，將 **Opcode URL** 填入：

```
https://raw.githubusercontent.com/gn1394594329/Resources/main/blueprint.xml
```

## 支援伺服器

| 伺服器 | 目前版本 |
|--------|---------|
| EN/DE/FR/JP | 2026.03.07 |
| CN | 2026.03.12 |
| KR | 2026.02.06 |
| TC（繁中服） | 2026.05.26 |
